# Widget Pattern Assets — روح المسلم

Premium Islamic pattern overlays for widget backgrounds.
Replace these placeholder PNGs with your own designs.

## Specifications
- **Size**: 400×400px (tiled pattern)
- **Format**: PNG with transparency
- **Opacity**: Design at 100% — the app applies opacity (10-15%) at render time
- **Color**: White (#FFFFFF) on transparent background (works on any dark gradient)

## Files

| Filename | Description | Theme |
|----------|-------------|-------|
| `pattern_geometric.png` | Islamic geometric tessellation (hexagonal/octagonal) | Mosque Green |
| `pattern_arabesque.png` | Classic arabesque floral vine pattern | Kaaba Gold |
| `pattern_stars.png` | 8-pointed Islamic star (Rub el Hizb) repeating | Royal Purple |
| `pattern_waves.png` | Flowing wave/water pattern (رحمة) | Ocean Blue |
| `pattern_desert.png` | Sand dune ripple / desert landscape pattern | Desert Sand |
| `pattern_floral.png` | Iznik-style floral tile motif | Emerald Night |
| `pattern_mashrabiya.png` | Mashrabiya (مشربية) lattice screen pattern | Midnight Rose |

## Design Tips
- Keep patterns subtle — they're decorative overlays, not main content
- Test on both light and dark widget backgrounds
- Use geometric precision for Islamic aesthetic authenticity
- Avoid any figurative/representational imagery (Islamic art convention)
